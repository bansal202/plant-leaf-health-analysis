Plant Leaf Health Analysis 🌿

Project Overview

Plant Leaf Health Analysis is an educational Python project that analyzes the colors in an uploaded plant leaf image.

The application displays the approximate percentage of green-toned and brown-toned pixels in the complete image.

Note: This project is for educational purposes only. It does not diagnose plant diseases or recommend treatments.

Features

- Upload leaf images in JPG, JPEG, and PNG formats.
- Display the uploaded image.
- Calculate green-toned pixel percentage.
- Calculate brown-toned pixel percentage.
- Show results in a simple web interface.

Technologies Used

- Python
- Streamlit
- NumPy
- Pillow

Project Files

- "app.py" — Main Python application.
- "requirements.txt" — Required Python libraries.
- "README.md" — Project documentation.

Installation and Execution

1. Install Python 3.10 or newer.

2. Download or clone this repository.

3. Open a terminal in the project folder.

4. Install the required libraries:
   
   "python -m pip install -r requirements.txt"

5. Run the application:
   
   "python -m streamlit run app.py"

6. Open the local URL displayed in the terminal, usually "http://localhost:8501".

How to Use

1. Start the application.
2. Upload a plant leaf image.
3. View the image and the green-toned and brown-toned pixel percentages.
